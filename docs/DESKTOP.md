# NOVA AI Cloud — نسخة سطح المكتب (Windows)

<div dir="rtl">

## ما هذه النسخة؟

تطبيق **Windows حقيقي** بنافذة مستقلة (لا يحتاج متصفح)، مبني بـ **Tauri 2** ومثبّت **NSIS**:

```
NOVA-AI-Cloud-Setup.exe          ← مثبّت NSIS (اختصارات + Uninstaller)
NOVA-AI-Cloud-Portable.exe       ← نسخة محمولة اختيارية (بدون تثبيت)
```

### المعمارية — نقطة مهمة

Tauri غلاف نافذة فقط، **ولا يشغّل الخادم من تلقاء نفسه**. لذلك:

```
┌───────────────────────────────────────────────────────────┐
│  غلاف Tauri (Rust، صغير)                                   │
│   1. يشغّل nova-server.exe  (sidecar مُضمَّن في الموارد)    │
│   2. ينتظر /api/health حتى يجيب                            │
│   3. يفتح النافذة على http://127.0.0.1:8787                 │
│   4. يقتل الـ sidecar عند الخروج                           │
└───────────────┬───────────────────────────────────────────┘
                │ 127.0.0.1 فقط
┌───────────────▼───────────────────────────────────────────┐
│  nova-server.exe  (sidecar — ملف تنفيذي واحد)              │
│   • كل الـ API والوكيل البرمجي (نفس كود Workers)           │
│   • الواجهة المبنية مُضمَّنة داخله (لا يحتاج ويب سيرفر)     │
│   • قاعدة البيانات: ملفات في <مجلد التطبيق>\nova-data      │
│   • النماذج: عبر الإنترنت (OpenRouter / Cloudflare) —      │
│     **لا تُضمَّن أي أوزان نماذج داخل الـ exe**               │
└───────────────────────────────────────────────────────────┘
```

نفس الكود تماماً يُستخدم في نسخة الويب — **نسخة الويب لم تُحذف ولم تتغير**.

## كيف تحصل على NOVA-AI-Cloud-Setup.exe

### الطريقة الموصى بها: GitHub Actions (بناء + اختبار على ويندوز حقيقي)

0. **عدّل سطراً واحداً** في `apps/desktop/src-tauri/tauri.conf.json`:
   استبدل `OWNER` في `plugins.updater.endpoints` باسم حسابك/مستودعك الفعلي
   (مثلاً `https://github.com/username/nova-ai-cloud/releases/latest/download/latest.json`).
1. ارفع هذا المستودع إلى GitHub.
2. افتح تبويب **Actions** ← شغّل workflow باسم **`desktop-windows`**
   (يعمل تلقائياً أيضاً عند كل push إلى `main`).
3. انتظر الوظائف الثلاث:

| الوظيفة | النظام | ماذا تفعل |
|---|---|---|
| `checks` | ubuntu | typecheck صارم + 121 اختباراً |
| `build` | **windows-latest** | بناء الواجهة ← sidecar exe ← مثبّت NSIS + Portable، مع فحوصات الملفات |
| `test-install` | **windows-latest** | **تثبيت صامت حقيقي** ← فحص الاختصارات ← تشغيل التطبيق ← التأكد أنه شغّل خادمه ← **إزالة كاملة** |

4. **استخراج ملف الـ EXE من الـ Artifacts**:
   - في صفحة الـ run الناجح، انزل إلى قسم **Artifacts**
   - نزّل **`NOVA-Windows-x64`** (ملف zip)
   - فك الضغط → تحصل على `NOVA-AI-Cloud-Setup.exe` و`NOVA-AI-Cloud-Portable.exe`
   - تُحفظ ٣٠ يوماً؛ للاحتفاظ الدائم ارفعها كـ Release (انظر أدناه)

> ⚠️ **أمانة**: لو فشل أي فحص داخل الـ Runner، يفشل الـ pipeline — لا يوجد نجاح مُدَّعى.
> وأنا (بيئة التطوير) على Linux ولا أملك ويندوز، لذا **لا أستطيع** اختبار المثبّت بنفسي؛
> الاختبار الحقيقي يحدث في `test-install` أو على جهازك.

### تفعيل فحص الذكاء الاصطناعي الحي (اختياري)

في المستودع: **Settings → Secrets and variables → Actions** ← أضف
`OPENROUTER_API_KEY`. عندها تتحقق وظيفة `build` من أن نموذجاً حقيقياً يجيب
من ثنائي الـ sidecar على ويندوز (`CI-AI-OK`).

## التثبيت

1. شغّل `NOVA-AI-Cloud-Setup.exe`
2. إن ظهر تحذير **Windows SmartScreen**: اضغط *More info* ثم *Run anyway*
   (طبيعي لأي exe غير موقّع رقمياً بشهادة شراء).
3. التثبيت **لكل مستخدم** (لا يحتاج صلاحيات مدير) في:
   ```
   %LOCALAPPDATA%\ai.nova.cloud\        (أو مجلد برامج المستخدم)
   ```

### ما ينشئه المثبّت

| العنصر | المسار |
|---|---|
| اختصار سطح المكتب | `%USERPROFILE%\Desktop\NOVA AI Cloud.lnk` |
| مجلد قائمة Start | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\NOVA AI Cloud\` |
| اختصار الإزالة | نفس المجلد ← `Uninstall NOVA AI Cloud.lnk` |
| قيد في «إضافة/إزالة البرامج» | باسم **NOVA AI Cloud** |
| الـ sidecar | `<مجلد التثبيت>\sidecar\nova-server.exe` |

## أول تشغيل — مفتاح النماذج

التطبيق **لا يحتوي مفتاحاً**. عند أول تشغيل ستظهر لك حالة «لا يوجد مزوّد مُعَد» بصدق.

أنشئ ملفاً باسم **`.env`** في **مجلد التثبيت** (نفس مكان `nova-server.exe`'s الأب):

```
OPENROUTER_API_KEY=sk-or-v1-....
NOVA_PROVIDER_PRIORITY=openrouter,workers-ai,custom
```

ثم أعد تشغيل التطبيق. (مفتاح OpenRouter مجاني بدون بطاقة: openrouter.ai/settings/keys)

> مكان البيانات والمحادثات: `<مجلد التثبيت>\nova-data\` — نسخها احتياطياً = نسخ مجلدك.

### لو المنفذ 8787 محجوز

اضبط متغير بيئة للمستخدم `NOVA_PORT` برقم آخر (مثلاً 8790) وأعد التشغيل.

## التحديثات

نظام التحديثات **مُركَّب وجاهز** (tauri-plugin-updater) لكنه لا يعمل إلا بعد نشر أول إصدار موقّع:

1. أضف سرّين في المستودع:
   - `TAURI_SIGNING_PRIVATE_KEY` ← محتوى `apps/desktop/src-tauri/.keys/nova-ai-cloud.key`
     (الملد موجود محلياً عندك، **لا ترفعه إلى git**)
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` ← كلمة المرور التي اخترتها عند توليد المفتاح
2. فعّل إنتاج حزم التحديث في `tauri.conf.json`:
   ```json
   "bundle": { "createUpdaterArtifacts": "v1Compatible" }
   ```
3. اصنع tag مثل `v0.2.0` ← يعمل workflow **`release.yml`** الذي يبني وينشر
   Release فيه `latest.json` + الحزم الموقّعة.
4. التطبيق المثبّت يفحص `.../releases/latest/download/latest.json` ويحدّث نفسه
   بصيغة `passive` (نافذة تثبيت هادئة).

> بدون هذه الخطوات يبقى التطبيق يعمل كاملاً — فقط لن يجد تحديثات. لا شيء يفشل بصمت.

## الإزالة

أي طريقة من:
- **Start** ← `NOVA AI Cloud` ← `Uninstall NOVA AI Cloud`
- أو **إعدادات → Apps → NOVA AI Cloud → Uninstall**
- أو `<مجلد التثبيت>\uninstall.exe`

ما تُزيله: البرنامج، الـ sidecar، اختصار سطح المكتب، مجلد قائمة Start، قيد السجل.
ما **تُبقيه** (عن قصد): مجلد `nova-data` فيه محادثاتك ومشاريعك — احذفه يدوياً إن أردت محو كل شيء.

---

## النسخة المحمولة

`NOVA-AI-Cloud-Portable.exe` — شغّله من أي مجلد بدون تثبيت.
ضع `.env` **بجانبه** مباشرة، وبياناته تُكتب في `nova-data` بجانبه أيضاً.
(لا ينشئ اختصارات ولا قيد إزالة — هذه طبيعة النسخ المحمولة.)

## ماذا اختُبر أين؟ (بصراحة كاملة)

| ماذا | أين | النتيجة |
|---|---|---|
| الـ sidecar: واجهة مضمّنة + API + محادثة حقيقية + حفظ | **Linux** (بيئة التطوير) | ✅ نجح — نموذج OpenRouter ردّ فعلاً |
| حزمة CJS والثثنائي pkg | Linux | ✅ |
| بناء المثبّت + فحوصات الملفات + PE check | **Windows Runner** (CI) | يُنفَّذ عند كل run |
| تثبيت صامت + اختصارات + تشغيل + خادم + إزالة | **Windows Runner** (CI) | يُنفَّذ عند كل run |
| ردّ نموذج حقيقي من ثنائي ويندوز | Windows Runner (يتطلب السر) | اختياري |
| تشغيل المثبّت بيد بشر على ويندوز | **جهازك** | لم يُنفَّذ بعد — بلّغني بأي خطأ |

**ما لم يُختبر**: لا توجد آلة ويندوز في بيئة التطوير، لذلك أي claim باختبار ويندوز
خارج الـ Runner أو جهازك سيكون كذباً — ولن أقوله.

## استكشاف الأخطاء

| العرض | السبب المحتمل | الحل |
|---|---|---|
| SmartScreen يحذّر | exe غير موقّع | More info → Run anyway |
| نافذة بيضاء/خطأ اتصال | الـ sidecar لم يعمل | افحص `<مجلد التثبيت>\nova-data\..` والسجل؛ تأكد أن منفذ 8787 فارغ أو اضبط `NOVA_PORT` |
| «لا يوجد مزوّد مُعَد» | لا مفتاح | أنشئ `.env` كما أعلاه |
| الشاشة تطلب WebView2 | ويندوز قديم بدون WebView2 | المثبّت ينزّله تلقائياً (bootstrapper) — يحتاج إنترنت |
| التطبيق لا يُغلق الخادم | إغلاق قسري | المهمة تُقتل عند الخروج الطبيعي؛ إن علّق: Task Manager ← nova-server.exe |
